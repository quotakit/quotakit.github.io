# quotakit.github.io

Source for [quotakit.github.io](https://quotakit.github.io) — free sales-ops calculators (commission, incentive payout, quota attainment, pipeline coverage) and the catalog of QuotaKit spreadsheet templates and Claude skills.

`build/` holds the generators: the five spreadsheet templates (openpyxl, formulas only), the listing-image composer, the packager and the static-site builder. The `build` workflow rebuilds everything on every push and deploys the site with GitHub Pages.

Created with AI assistance; designed, curated and tested by QuotaKit.
